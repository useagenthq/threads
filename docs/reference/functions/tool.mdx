Input and output types are inferred from the schemas.

Import from `@threads/core` (TypeScript) or `threads` (Python).

<CodeGroup>

```ts TypeScript
function tool(options: {
  name: Name;
  description: string;
  input: z.ZodType<Input>;
  output?: z.ZodType<Output>;
  runs: "host" | "sandbox";
  execute?: (input: Input, ctx: RunContext<Deps>) => Promise<Output>;
  effect?: EffectClass;
  dedupWindowMs?: PosInt;
  reconcile?: { lookup: (effectKey: string, ctx: RunContext<Deps>) => Promise<LookupResult<Output>>; finality: "final" | "nonfinal" };
  endsTurn?: boolean;
}): Tool<Input, Output, Deps>
```

```python Python
def tool(
    *,
    name: Name,
    description: str,
    input: type[Input],
    runs: Literal["host", "sandbox"],
    execute: Callable[[Input, RunContext[Deps]], Awaitable[Output]] | None = None,
    effect: EffectClass = "unguarded",
    dedup_window_ms: PosInt | None = None,
    reconcile: Reconcile[Output, Deps] | None = None,
    ends_turn: bool = False,
) -> Tool[Input, Output, Deps]
```

## Parameters

<ParamField body="name" type={"Name"} required>
   
</ParamField>

<ParamField body="description" type={"string"} required>
   
</ParamField>

<ParamField body="input" type={"z.ZodType<Input>"} required>
  Tool arguments are parsed with it at the boundary; its JSON Schema is the pinned input_schema.
</ParamField>

<ParamField body="output" type={"z.ZodType<Output>"}>
  TypeScript only. Pinned output_schema. A result that fails it is an error result; the effect still happened.
</ParamField>

<ParamField body="runs" type={"\"host\" | \"sandbox\""} required>
  Required, no default. Only "host" is supported today; "sandbox" is a setup error.
</ParamField>

<ParamField body="execute" type={"(input: Input, ctx: RunContext<Deps>) => Promise<Output>"}>
  runs host: required. The value is the result; a thrown error becomes an error tool_result the model sees.
</ParamField>

<ParamField body="effect" type={"EffectClass"} default={"unguarded"}>
  Undeclared tools are unguarded: uncertainty always parks.
</ParamField>

<ParamField body="dedupWindowMs / dedup_window_ms" type={"PosInt"}>
  Required exactly when effect is idempotent.
</ParamField>

<ParamField body="reconcile" type={"{ lookup: (effectKey: string, ctx: RunContext<Deps>) => Promise<LookupResult<Output>>; finality: \"final\" | \"nonfinal\" }"}>
  Required exactly when effect is reconcilable. finality is the tool's declared LookupCapability: the runtime accepts a not_found answer as final only when it is final; under nonfinal a not_found is treated as not_found_nonfinal and the call parks.
</ParamField>

</ParamField>
