---
title: Structured output
description: Get a typed, validated value back from a run instead of free text.
icon: braces
---

<Note>
TypeScript only today. Python's `agent()` has no `output` option yet; a Python run's `output` is always the final text.
</Note>

Pass a Zod schema as `output` and a completed run's `output` is typed as that schema. The model returns its answer through a `final_output` tool whose input is your schema. threads validates each answer; if one fails, the model sees the validation error and tries again.

```ts TypeScript
const Triage = z.object({
  severity: z.enum(["low", "medium", "high"]),
  summary: z.string(),
  needsHuman: z.boolean(),
});

const triage = agent({
  instructions: "Triage the incoming support ticket.",
  model: scriptedModel({
    responses: [
      {
        content: [{ type: "tool_use", call_id: "c1", name: "final_output", input: { severity: "urgent", summary: "x", needsHuman: true } }],
        stop_reason: "tool_use",
        usage,
      },
      {
        content: [{ type: "tool_use", call_id: "c2", name: "final_output", input: { severity: "high", summary: "Checkout is down", needsHuman: true } }],
        stop_reason: "tool_use",
        usage,
      },
    ],
  }),
  output: Triage,
  outputRetries: 2,
});

const result = await triage.run("Nobody can pay since 9am!", { store: sqlite(":memory:") });
if (result.status === "completed") {
  const { severity, needsHuman } = result.output; // typed as z.infer<typeof Triage>
  console.log(severity, needsHuman);
}
```

The scripted model's first answer uses `"urgent"`, which isn't in the enum, so it is rejected and the second answer is accepted. With a real model you only write the schema.

## Options

<ParamField path="output" type="z.ZodType">
  The schema of the final answer. The agent's type becomes `Agent<Deps, z.infer<typeof schema>>`.
</ParamField>
<ParamField path="outputRetries" type="number" default="2">
  When this many answers have failed (rejected by the schema, or plain text with no `final_output` call), the run ends `failed` with code `output_invalid`.
</ParamField>

Each accepted or rejected answer is recorded in the log, so you can see in the [timeline](/evals/timeline) exactly what the model tried.
