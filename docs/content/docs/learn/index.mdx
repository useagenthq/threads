The guides explain one feature at a time. These four tutorials build one program instead. You start
with a support agent that answers from its instructions, and finish with the same agent running a
team of two. Each step adds one idea and leaves you with a file you can run.

Every program here runs offline on the [scripted model](/docs/evals/testing), so you need no API key
and no network to follow along, and the output in each page is what it printed when it was written.
Both languages are in every step.

Before you start, set up threads from a clone: [Installation](/docs/installation).
