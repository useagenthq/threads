Pure: no I/O, no env reads, no sockets. Checked by Agent.check() or on the first run.

Import from `@threads/core` (TypeScript) or `threads` (Python).

## Parameters

<Field name="model" type={"Model"} required>
  See [Model](/docs/reference/types/Model).
</Field>

<Field name="instructions" type={"string"} default={""}>
  Pinned system text (the pinned prompt prefix).
</Field>

<Field name="name" type={"Name"} default={"agent"}>
  Unique among the agents a host, subagent list or handoff list names.
</Field>

<Field name="tools" type={"readonly (Tool | McpServer)[]"}>
  App tools and MCP servers. Built-in tools come from the sandbox and the options below.
</Field>

<Field name="extensions" type={"readonly Extension[]"}>
  Instructions and hooks run in this order.
</Field>

<Field name="sandbox" type={"Sandbox"}>
  Absent: no sandbox tools (bash, files, browser, computer). See [Sandbox](/docs/reference/types/Sandbox).
</Field>

<Field name="memory" type={"MemoryProvider"}>
  See [MemoryProvider](/docs/reference/types/MemoryProvider).
</Field>

<Field name="memoryWrite / memory_write" type={"\"deny\" | \"ask\" | \"allow_principal\" | \"allow\""} default={"ask"}>
  Write authority for save_memory.
</Field>

<Field name="knowledge" type={"KnowledgeProvider"}>
  See [KnowledgeProvider](/docs/reference/types/KnowledgeProvider).
</Field>

<Field name="skills" type={"readonly Skill[]"}>
  Pinned in config_hash (name, description, sha256 of body). The system prompt lists them after the extension instructions as "Skills you can load with load_skill:" then one "- name: description" line each, in the given order; load_skill (pinned only when this is non-empty) appends the body as injected&#123;source: skill, trust: trusted_instruction, origin: &#123;id: name, version: sha256 of body&#125;&#125;. Unique names; a description is one non-empty line.
</Field>

<Field name="output" type={"z.ZodType<Output>"}>
  Structured final output. Absent: completed.output is the final text.
</Field>

<Field name="outputRetries / output_retries" type={"number"} default={"2"}>
  Failed candidates per turn (a rejected final_output or a plain-text end) before turn_completed&#123;output_invalid&#125;. An integer from 0 to 2^53-1; anything else is ConfigError invalid_config.
</Field>

<Field name="subagents" type={"readonly (Agent<unknown, unknown>)[]"}>
  Agents spawn_agent may start, by name. Team tools come with them. A subagent with output reports the canonical JSON of its accepted output.
</Field>

<Field name="handoffs" type={"readonly (Agent<unknown, unknown>)[]"}>
  Agents this one may hand the conversation to, pinned as policy.handoffs.
</Field>

<Field name="fallback" type={"readonly Model[]"}>
  Fallback models in order. With the default fallback_scope turn, the next user_input reverts to the settings before the fallback (settings_changed&#123;reason: revert&#125;), gated by before_model_switch.
</Field>

<Field name="permissions" type={"Partial<Policy.permissions>"} />

<Field name="approvers" type={"readonly Principal[]"}>
  Who may answer approval challenges and resolve parked effects for runs this agent roots, its subagents and handoff targets included.
</Field>

<Field name="budget" type={"Budget"}>
  Thread budget.
</Field>

<Field name="on_unknown_usage" type={"Policy.on_unknown_usage"} default={"upper_bound"}>
  Python only.
</Field>

<Field name="retry" type={"Partial<Policy.retry>"} />

<Field name="context" type={"Partial<Policy.context>"} />

<Field name="egress" type={"readonly string[] | \"unenforced\""}>
  Sandbox egress allowlist of hosts. [] is deny-all. unenforced opts in to a provider that can't enforce it; stub mode then refuses. Host allowlists are not supported yet in either language: use [] (deny-all) or "unenforced".
</Field>

<Field name="web" type={"{ fetch?: boolean; search?: SearchBackend }"}>
  Host-side web_fetch and web_search.
</Field>

<Field name="git" type={"{ credential: Secret; forgeUrl?: string; apiUrl?: string }"}>
  Enables the git gateway tools git_clone, git_fetch, git_push and open_pull_request. The forge is GitHub; the credential is revealed only on the host and never enters the sandbox.
</Field>

<Field name="computer" type={"boolean"} default={"false"}>
  Pins computer_screenshot (read_only) and computer (actions, unguarded). Needs a sandbox whose info.desktop is native or image; otherwise a setup error capability_missing.
</Field>

<Field name="lsp" type={"{ languages: readonly string[] }"}>
  Pins lsp for these languages (typescript, python, go, rust), run in the sandbox image's language servers. Needs a sandbox; an unknown language is unknown_preset. A server that isn't installed or ready answers unavailable at run time.
</Field>
