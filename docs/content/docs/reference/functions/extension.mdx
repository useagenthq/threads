Trusted host code, not a security boundary.

Import from `@threads/core` (TypeScript) or `threads` (Python).

## Parameters

<Field name="name" type={"Name"} required>
  Unique; tools are namespaced &lt;ext>__&lt;tool>.
</Field>

<Field name="tools" type={"readonly (Tool | McpServer)[]"} />

<Field name="instructions" type={"string"} default={""}>
  Static; goes into the system prompt after the base instructions.
</Field>

<Field name="hooks" type={"Hooks<Deps>"}>
  See [Hooks](/docs/reference/types/Hooks).
</Field>

<Field name="on" type={"Record<string, (event: Event) => Promise<void>>"}>
  Observers keyed by event type, or "*". Committed events, delivered after append; can't block or change execution.
</Field>

<Field name="setup" type={"() => Promise<void>"}>
  Runs once at check() or first run. Throwing is a ConfigError.
</Field>

<Field name="hookTimeoutMs / hook_timeout_ms" type={"PosInt"} default={"5000"} />
