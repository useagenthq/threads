## Parameters

<Field name="store" type={"Store"} required>
  The store the team's logs live in, the one its lead ran with. See [Store](/docs/reference/types/Store).
</Field>

<Field name="ref" type={"TeamRef"} required>
  Which team, as team.ref gives it. See [TeamRef](/docs/reference/types/TeamRef).
</Field>

<Field name="principal" type={"Principal"} required>
  Who acts through this handle. Every request it makes is recorded with this principal; another tenant's is forbidden.
</Field>

## Returns

[`Team`](/docs/reference/types/Team)

**Returns an error value** with one of these codes: `not_found`, `forbidden`.
