The host owns the connection and credentials; an unreachable server is a ConfigError naming it.

Import from `@threads/mcp` (TypeScript) or `threads.mcp` (Python).

## Parameters

<Field name="name" type={"Name"} required>
  Tools are named mcp__&lt;name>__&lt;tool>.
</Field>

<Field name="url" type={"string"}>
  The server's URL, for a server reached over HTTP: Streamable HTTP, falling back to the older SSE transport. Exactly one of url or command; omit it for a stdio server.
</Field>

<Field name="headers" type={"Record<string, string | Secret>"} default={"{}"}>
  HTTP headers sent with every request to a url server, such as an Authorization header. A value can be a secret(), revealed only on the host. Default &#123;&#125; sends none.
</Field>

<Field name="command" type={"string"}>
  The command that starts a stdio server, run on the host with args. Exactly one of url or command; omit it for a url server.
</Field>

<Field name="args" type={"readonly string[]"} default={"[]"}>
  Arguments passed to command. Default [] passes none.
</Field>

<Field name="env" type={"Record<string, string | Secret>"} default={"{}"}>
  Environment variables for the command's process. Only PATH and HOME come from the host; everything else must be given here. A value can be a secret(), revealed only on the host. Default &#123;&#125;.
</Field>

<Field name="runs" type={"\"host\" | \"sandbox\""} default={"host"}>
  sandbox: stdio server inside the sandbox, with no host credentials. Only "host" is supported today; "sandbox" is a setup error.
</Field>

<Field name="tools" type={"{ allow?: readonly string[]; deny?: readonly string[] }"}>
  Filters the server's tools, by the server's own tool names, before they are pinned. Omitted: every tool the server lists is pinned.
</Field>

<Field name="tools.allow" type={"readonly string[]"}>
  Only tools with these names are kept. Omitted: every name is allowed.
</Field>

<Field name="tools.deny" type={"readonly string[]"}>
  Tools with these names are dropped, even when allow lists them. Omitted: none are dropped.
</Field>

<Field name="effect" type={"EffectClass"} default={"unguarded"}>
  The effect class every tool from this server is pinned with. Use read_only for a server whose tools change nothing; the default unguarded means an uncertain call parks and is never retried. idempotent needs dedup_window_ms.
</Field>

<Field name="defer" type={"boolean"} default={"false"}>
  true: the model sees only this server's tool names, listed in tool_search's description, until it loads them with tool_search; their descriptions and schemas are sent only after a load. Use it for a server with many tools. context.defer_tools decides whether the flag is honoured. Default false.
</Field>

<Field name="dedupWindowMs / dedup_window_ms" type={"PosInt"}>
  Milliseconds within which the server dedups a repeated call that carries the same effect key (sent as the call's _meta threads/effect_key). Required exactly when effect is idempotent; giving it with any other effect is a setup error invalid_config. Omitted: no dedup window (effect is not idempotent).
</Field>
