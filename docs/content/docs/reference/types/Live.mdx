Live evals need agents too. For a simulated case, budget covers the whole conversation; for every other run, one run.

## Fields

<Field name="judge" type={"Model"} required>
  The model that grades each case against its rubric (judge.v1 instructions, one call per case).
</Field>

<Field name="budget" type={"Budget"} required>
  The run budget of every agent run and every judge run, subagents included. A run it stops is an error with budget_exhausted.
</Field>

<Field name="rubric" type={"readonly string[]"} default={"[]"}>
  Criteria added after each case's own.
</Field>

<Field name="user" type={"Model"}>
  The model that plays the user of a case whose simulate is kind model (simulated_user.v1 instructions, one call per user message). A case that needs one without it is ConfigError invalid_config naming the case, before any model call.
</Field>
