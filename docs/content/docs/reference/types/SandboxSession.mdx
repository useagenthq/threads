### exec

A timeout kills the whole process group.

<Tabs items={["TypeScript", "Python"]} groupId="lang" persist>
<Tab value="TypeScript">

```ts
exec(command: readonly string[], context: SandboxContext, options: {
  cwd?: string;
  env?: Record<string, string>;
  timeoutMs?: PosInt;
  stdin?: Uint8Array;
  processKey: string;
}): Promise<Result<ExecOutput>>
```

</Tab>
<Tab value="Python">

```python
async def exec(
    command: Sequence[str],
    context: SandboxContext,
    *,
    cwd: str = "/workspace",
    env: Mapping[str, str] = {},
    timeout_ms: PosInt | None = None,
    stdin: bytes | None = None,
    process_key: str,
) -> Ok[ExecOutput] | Err[Failure]
```

</Tab>
</Tabs>

<Field name="command" type={"readonly string[]"} required>
  The program and its arguments, run directly as argv, not as a shell string. Pass ["/bin/sh", "-c", script] to use a shell. An empty command is a caller bug: exec throws (Python ValueError) before anything reaches the sandbox.
</Field>

<Field name="context" type={"SandboxContext"} required>
  The authority to re-check with context.fence() before starting the process. See [SandboxContext](/docs/reference/types/SandboxContext).
</Field>

<Field name="cwd" type={"string"} default={"/workspace"}>
  The absolute working directory inside the sandbox. A path outside the sandbox tree is invalid_path.
</Field>

<Field name="env" type={"Record<string, string>"} default={"{}"}>
  Exactly this env; nothing inherited. Each name is a shell variable name ([A-Za-z_][A-Za-z0-9_]*) and must not start with __t_, which the sandbox-side wrapper keeps for itself; any other name is a caller bug: exec throws (Python ValueError) before anything is sent.
</Field>

<Field name="timeoutMs / timeout_ms" type={"PosInt"}>
  Deadline in milliseconds. The framework's sandbox layer enforces it: once it passes, the call ends as timeout and the process group is terminated. When omitted, the command has no time limit.
</Field>

<Field name="stdin" type={"Uint8Array"}>
  Bytes fed to the process's standard input. When omitted, standard input is empty (/dev/null).
</Field>

<Field name="processKey / process_key" type={"string"} required>
  Durable identity of the process group: the call's effect key, recorded by effect_begin before dispatch, so recovery can terminate it after a crash.
</Field>

**Returns an error value** with one of these codes: `stale_epoch`, `cleanup_claim_lost`, `timeout`, `invalid_path`, `unavailable`.

### exportTree / export_tree

Stream /workspace as a tar archive: the archive on stdout, then exit_code 0; any other exit code means the export failed, and stderr says why. The archive is a sandbox response: the runtime parses it strictly before using it. Setuid, setgid and sticky bits are reported as the sandbox has them.

### importTree / import_tree

Extract a host-built tar archive into /workspace, keeping each entry's mode as the archive gives it but never its owner. The runtime's tree builder writes every mode as mode & 0o777, so setuid, setgid and sticky bits never survive an import (a sandbox extracting as root would keep them). Existing files at the archive's paths are replaced.
