## Fields

<Field name="path" type={"string"} required>
  The case directory that was written, &lt;dir>/&lt;name>.
</Field>

<Field name="portable" type={"boolean"} required>
  true when the case reruns offline from its directory alone.
</Field>

<Field name="reason" type={"OfflineReason"}>
  Why the case can't rerun offline, when it can't: artifact_missing, unsettled_effect, content_input, child_threads, team_calls or extension_events (reserved). It is still written, and runEvals skips it offline with this reason.
</Field>
