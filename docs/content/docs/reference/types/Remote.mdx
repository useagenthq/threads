<Callout>Opaque: build it with its factory and pass it on; it has no public members.</Callout>

## Methods

### tools

This remote as two pinned tools, to spread beside the thread's own tools. &lt;name> sends one message and is reconcilable with nonfinal finality: an uncertain outcome parks and is settled by a lookup that finds the message, by the transport proving nothing was sent, or by a person, never by an automatic re-send, and a lookup that finds nothing never proves absence. &lt;name>_status reads a task &lt;name> created, is read_only and sends nothing, and still records each task state it observes in this conversation's log. The card is fetched and pinned at the thread's first call of the remote. A task id this conversation's own log does not hold is refused by both tools, and nothing is sent and nothing is read.
