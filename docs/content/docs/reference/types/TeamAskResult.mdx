A union discriminated by `status`.

### AskOutcome

Any [`AskOutcome`](/docs/reference/types/AskOutcome).

### refused

<Field name="status" type={"\"refused\""} required>
  "refused": nothing was done; code says why.
</Field>

<Field name="code" type={"AskRefusal | OperatorRefusal | \"invalid_request\""} required>
  Why it was refused. invalid_request (a timeout_ms that is not a positive integer) is returned before any writer, so, like busy, it is never logged.
</Field>
