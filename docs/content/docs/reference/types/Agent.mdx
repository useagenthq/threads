## Methods

### run

Run one input to a terminal result. Needs no server. Python: an agent with app tools needs deps on every run; pass deps=None when its tools take none.

<Tabs items={["TypeScript", "Python"]} groupId="lang" persist>
<Tab value="TypeScript">

```ts
run(input: Input, options?: {
  thread?: ThreadId | Thread;
  store?: Store;
  deps?: Deps;
  budget?: Budget;
  principal?: Principal;
  ceiling?: Partial<Policy.permissions>;
  signal?: AbortSignal;
}): Promise<RunResult<Output>>
```

</Tab>
<Tab value="Python">

```python
async def run(
    input: Input,
    *,
    thread: ThreadId | Thread | None = None,
    store: Store | None = None,
    deps: Deps | None = None,
    budget: Budget | None = None,
    principal: Principal | None = None,
    ceiling: Policy.permissions | None = None,
) -> RunResult[Output]
```

</Tab>
</Tabs>

<Field name="input" type={"Input"} required>
  Text or ordered input parts.
</Field>

<Field name="thread" type={"ThreadId | Thread"}>
  Continue this thread (a handle continues its branch). Absent: a new thread.
</Field>

<Field name="store" type={"Store"}>
  See [Store](/docs/reference/types/Store).
</Field>

<Field name="deps" type={"Deps"}>
  Host-only dependencies for tools and hooks (RunContext.deps). Never serialized. Required when Deps is not null.
</Field>

<Field name="budget" type={"Budget"}>
  Run budget, recorded on the user_input. Covers the thread and every descendant.
</Field>

<Field name="principal" type={"Principal"}>
  The verified sender of this input.
</Field>

<Field name="ceiling" type={"Partial<Policy.permissions>"}>
  The principal and host ceiling. Every permission decision of this run, of its subagents and of every handoff target it starts is also decided under it, in the ceiling's own mode; the stricter decision wins and a tie reports the thread's own. A handoff target is capped by the ceilings of the run that handed off, never by the source agent's own policy. Absent: no ceiling.
</Field>

<Field name="signal" type={"AbortSignal"}>
  TypeScript only. Local cancellation. Python uses task cancellation. Durable cancellation is Thread.cancel().
</Field>

**Throws** `ConfigError` for a definition that can't run.

### check

TypeScript only. Validate the definition and resolve setup (secrets, MCP handshakes, capabilities) without starting a run.

```ts title="TypeScript"
check(): Promise<Result<void>>
```

**Returns an error value** with one of these codes: `invalid_config`, `missing_secret`, `unknown_preset`, `duplicate_name`, `capability_missing`, `mcp_unreachable`, `budget_unenforceable`, `permission_rule_invalid`, `hosted_tool_unsupported`, `egress_policy_unsupported`.
