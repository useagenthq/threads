A union discriminated by `status`.

### started

<Field name="status" type={"\"started\""} required>
  "started": the member exists in state starting; its task is queued.
</Field>

<Field name="member" type={"MemberRef"} required>
  The new member: its name is &lt;agent>-&lt;k>.
</Field>

### refused

<Field name="status" type={"\"refused\""} required>
  "refused": nothing was done; code says why.
</Field>

<Field name="code" type={"StartRefusal | OperatorRefusal | \"invalid_request\""} required>
  Why it was refused. forbidden on a host team: the name is no host member of it, its generation is still live, or the supervisor restarted it rather than stopping it. invalid_request (no task in a lead's team) is returned before any writer, so, like busy, it is never logged.
</Field>

<Field name="detail" type={"InvalidDefinition"}>
  Present exactly when code is invalid_definition: which field, why, and what is allowed.
</Field>
