Every request is recorded in the team log as the principal it acts for; only busy, returned before the log could be written, is not.

<Callout>A handle returned by the library.</Callout>

## Properties

<Field name="ref" type={"TeamRef"} required>
  This team's tenant and id.
</Field>

## Methods

### start

Starts a member from an agent the team lists, with task as its first input. Recorded in the team log as an operator request.

<Tabs items={["TypeScript", "Python"]} groupId="lang" persist>
<Tab value="TypeScript">

```ts
start(agent: Name, task: string, options?: {
  label?: string;
  instructions?: string;
  tools?: readonly string[];
  model?: string;
  idempotencyKey?: string;
}): Promise<TeamStartResult>
```

</Tab>
<Tab value="Python">

```python
async def start(
    agent: Name,
    task: str,
    *,
    label: str | None = None,
    instructions: str | None = None,
    tools: Sequence[str] | None = None,
    model: str | None = None,
    idempotency_key: str | None = None,
) -> TeamStartResult
```

</Tab>
</Tabs>

<Field name="agent" type={"Name"} required>
  The agent to start, by name.
</Field>

<Field name="task" type={"string"} required>
  The member's first input; it sees nothing else.
</Field>

<Field name="label" type={"string"}>
  A display name for the member, 1-64 characters with no control or format character, not operator. Never hashed and never shown to a model. Omitted: none.
</Field>

<Field name="instructions" type={"string"}>
  A dynamic agent only: instructions added after the template's own, in a block marked as written by operator. At most 16 KiB. Omitted: the template's alone.
</Field>

<Field name="tools" type={"readonly string[]"}>
  A dynamic agent only: the member's tools, a subset of the template's (the framework tools are always kept). Omitted: all of the template's.
</Field>

<Field name="model" type={"string"}>
  A dynamic agent only: a key of the template's models. Omitted: the first key.
</Field>

<Field name="idempotencyKey / idempotency_key" type={"string"}>
  Makes a retry safe: the same key, principal and body return (or re-attach to) the first request's outcome. Scoped to this team and operation. Omitted: every call is a new request.
</Field>

</Field>

### members

Every member of the team, the lead included, with its state and, once idle or ended, its result. A pure read.

</Tab>

</Tab>

### events

**Phase 2, not yet available** (lane 29-teams-phase2-29b): Until then a cursor of any other epoch restarts the feed, follow is not supported, and GET /v1/teams/&#123;team&#125;/events is not served. The team's audit feed: every committed event of every team log, as stored (results keep their artifact refs, so this never raises StoreCorruptError). A pure read that drives nothing.

<Tabs items={["TypeScript", "Python"]} groupId="lang" persist>

```ts
events(options?: {
  after?: TeamCursor;

```

</Tab>
<Tab value="Python">

```python
async def events(
    *,
    after: TeamCursor | None = None,
) -> Ok[AsyncIterator[TeamItem]] | Err[Failure]
```

</Tab>

<Field name="after" type={"TeamCursor"}>
  Resume after this cursor. A cursor of an older epoch first yields epoch_restarted; one from a later epoch, or past the head of the current one, is invalid_cursor. Omitted: from the start. See [TeamCursor](/docs/reference/types/TeamCursor).
</Field>

**Returns an error value** with one of these codes: `invalid_cursor`.
