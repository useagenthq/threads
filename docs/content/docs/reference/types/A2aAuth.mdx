---
title: "A2aAuth"
description: "A credential for a remote, from bearer()."
icon: "Package"
---

Resolved on the host at setup and sent only in the Authorization header of requests to the pinned interface's origin; it never enters the log, a prompt, a stored request body or a sandbox.

<Callout>Opaque: build it with its factory and pass it on; it has no public members.</Callout>
